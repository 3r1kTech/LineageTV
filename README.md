# LineageTV
A (hopefully soon) way to connect a LineageOS phone/tablet to a LineageOS TV Box.

# Installation
View the wiki for info on how to set LineageTV up.

# Why?
When you use a LineageOS device without MindTheGapps or OpenGapps (Probally for better performance), using Google TV control from the notification center no longer works. This project will hopefully fix this issue.
